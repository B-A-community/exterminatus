# Подключение плагина к терминалу Exterminatus

Гайд для авторов плагинов B&A community. Терминал поддерживает только наши
плагины и родные команды SketchUp. Чужие плагины он не подхватывает.

После подключения команда плагина описывается один раз. Из этого описания
получаются:

- пункт меню и кнопка на панели;
- команда терминала с вопросами в строке, как в Rhino;
- справка `Help <команда>`;
- поиск по русским словам и пресеты.

Без терминала плагин тоже работает. Пункт меню и кнопка остаются, а команда
запускается сама.

Пошаговая инструкция для одного плагина лежит в [INTEGRATE.md](INTEGRATE.md),
рабочий пример — в [examples/hello_plugin](../examples/hello_plugin).

Версия API: 2 (Exterminatus 0.2).

## 1. Скопировать мост

Скопируйте [`src/exterminatus/terminal_bridge.rb`](../src/exterminatus/terminal_bridge.rb)
в папку плагина **как есть**, например в `src/<plugin>/terminal_bridge.rb`. Подключите
его до описания команд:

```ruby
Sketchup.require(File.join(__dir__, 'terminal_bridge'))
```

Мост определяет API `BACommunity::Terminal`. Порядок загрузки расширений
значения не имеет:

- если терминал не установлен или загрузится позже плагина, команды ждут в
  очереди, а меню и кнопки строятся сразу;
- если терминал уже загружен, мост только достраивает меню.

Файл не правьте. В каждом плагине своя копия, и SketchUp берёт код самой
новой из загруженных. Старая копия в соседнем плагине новой не мешает.
`PluginCheck` покажет, где лежит устаревшая копия.

## 2. Описать команду

```ruby
T = BACommunity::Terminal

T.command(
  id: 'PathCopy',                         # имя в терминале
  plugin: 'PathCopy Advanced',            # подпись в подсказках
  description: 'Copy the selected object along the selected path',
  aliases: %w[PC],                        # необязательно
  keywords: 'копия вдоль пути массив',    # русские слова для поиска
  examples: ['PathCopy 300', 'PathCopy step=1.2m mode=fit'],
  menu: 'Extensions/PathCopy Advanced',   # куда положить пункт меню
  menu_text: 'Copy Along Path',           # текст пункта (можно по-русски)
  toolbar: 'PathCopy Advanced',           # панель для кнопки
  icon: File.join(__dir__, 'icons', 'pathcopy.svg'),
  params: [
    { key: :objects, type: :selection, label: 'Select objects to copy' },
    { key: :step,  type: :length,  default: 500.mm, min: 1.mm },
    { key: :mode,  type: :option,  values: %w[Step Count Fit], default: 'Step', prompt: false }
  ]
) do |args|
  PathCopyAdvanced.run(args[:objects], step: args[:step], mode: args[:mode])
end
```

Регистрируйте один раз, в `main.rb` плагина, внутри той же защиты
`unless defined?(@ui_built)`, что и меню. Вызов `T.command` уже кладёт пункт в
меню и кнопку на панель. Свои `UI::Command`, `add_item` и `UI::Toolbar` для
этой команды больше не нужны.

`T.command` возвращает `UI::Command`. Его можно добавить ещё и в контекстное
меню плагина.

### Ключи

| Ключ | Значение |
|---|---|
| `id` | имя команды: английский CamelCase, только латиница и цифры (`PathCopy`, `RoofHip`) |
| `plugin` | имя плагина в подсказках и в `Commands` |
| `description` | одна короткая фраза по-английски |
| `aliases` | короткие синонимы латиницей (`PC`) |
| `keywords` | русские слова через пробел: по ним команду находят, набрав «копия» или «массив» |
| `examples` | строки для `Help <команда>` |
| `params` | параметры, раздел 4 |
| `preview` | `->(args, view) { ... }` — рисует результат, пока выбирают точку (раздел 5) |
| `repeat` | `->(args) { {...} }` — повтор команды, как у Line (раздел 5) |
| `menu` | путь меню: `'Extensions/PathCopy Advanced'`, `'Draw/Arch'` или массив |
| `menu_text` | текст пункта меню; по умолчанию — `id` с пробелами (`Path Copy`) |
| `tooltip` | подсказка кнопки; по умолчанию `menu_text` |
| `toolbar` | имя панели; панель создаётся и показывается сама |
| `icon` | путь к `.svg`/`.png` или `{ small:, large: }` |
| `separator` | `true` — разделитель в меню перед пунктом |
| `enabled` | `-> { ... }` — пункт серый, пока возвращает ложь |
| `checked` | `-> { ... }` — галочка у пункта |
| `fallback` | `-> { ... }` — что делает пункт меню без терминала (раздел 3) |

### Имена

- `id` уникален среди всех плагинов и команд SketchUp. Имена `Line`, `Move`,
  `Offset`, `Group`, `SetTag` уже заняты. Если имя занято, команда в терминал не
  попадёт, а `PluginCheck` скажет почему. Пункт меню при этом всё равно
  работает, но через запуск без терминала.
- Имя называет действие, а не плагин: `PathCopy`, а не `PathCopyAdvancedTool`.
  Приставку плагина давайте, только если без неё имя неоднозначно: `WallByLines`,
  а не `Wall`.
- Русский текст допустим только в `menu_text`, `keywords` и в значениях,
  которые вводит пользователь. В `id`, именах параметров и опциях — латиница:
  так их можно набрать в любой раскладке.

## 3. Пункт меню, кнопка и работа без терминала

Клик по пункту меню или кнопке зависит от того, установлен ли терминал.

**Терминал есть.** Команда запускается так, будто её набрали:

- она попадает в историю;
- вопросы идут в строке состояния и в поле Measurements;
- точки берутся кликом в модели.

Если вопрос требует ввода с клавиатуры, у курсора открывается строка
терминала. Если в этот момент ждала ответа другая команда, она отменяется, как
при смене инструмента.

**Терминала нет.** Работает сам мост:

- `:selection` берётся из выделения; если оно пустое, мост просит выделить;
- остальные параметры показываются одним окном `UI.inputbox` с последними
  значениями.

  Окно знает `:length`, `:number`, `:integer`, `:angle`, `:string`, `:option`
  (список) и `:bool` (Yes/No).
- если команде нужны точки (`:point`, `:vector`), мост говорит, что для неё
  нужен терминал.

Чтобы без терминала работал старый путь плагина (свой инструмент или свой
диалог), передайте `fallback:`:

```ruby
T.command(id: 'Beam', ..., fallback: -> { Sketchup.active_model.select_tool(BeamTool.new) }) do |args|
  ArchiTools::Beam.build(args[:start], args[:finish], args[:height])
end
```

## 4. Параметры

Терминал спрашивает параметры по очереди: показывает значение по умолчанию,
разбирает ввод и запоминает последние значения на время сеанса SketchUp.

```
PathCopy
Step <500 mm> ( Mode=Step  Preset ):
```

- Enter (или пробел в пустой строке) принимает значение по умолчанию.
- Клик по `Mode` перебирает варианты, по опции `:bool` переключает Yes/No.
  Клик по числовой опции спрашивает число. `Count=20` меняет опцию, не уходя с
  вопроса.
- Esc отменяет команду.
- Можно сразу в строке: `PathCopy 300`, `PathCopy step=1.2m mode=fit`.
  Позиционные значения идут по порядку `params`, именованные — как `Name=value`.
- Цепочка через `;`: `Top; ZoomExtents; PathCopy 300`.

| Поле | Значение |
|---|---|
| `key` | ключ в `args` (Symbol), обязателен |
| `name` | имя в строке; по умолчанию `key` в CamelCase (`:step_size` → `StepSize`). Только латиница |
| `label` | текст вопроса, если он длиннее имени: `'Point to move from'` |
| `type` | `:length`, `:number`, `:integer`, `:angle` (градусы), `:string`, `:option`, `:bool`, `:point`, `:vector`, `:scale`, `:selection` |
| `default` | значение по умолчанию. Для `:length` пишите `500.mm`: голое `500` — это 500 дюймов (`PluginCheck` это поймает) |
| `values` | варианты для `:option`, латиницей |
| `suggest` | для `:string`: варианты в подсказках, `-> { model.layers.map(&:name) }`. Ввести можно и другое |
| `prompt` | `true` (по умолчанию) — спрашивать по очереди; `false` — только опцией в скобках |
| `optional` | `true` — значение только из строки команды: не спрашивается и не запоминается |
| `min`, `max` | границы для чисел и длин |
| `ask_if` | `->(args) { ... }` — спрашивать, только когда вернёт истину |
| `description` | пояснение в `Help <команда>` |

`:length` понимает единицы модели и любые записи SketchUp: `500`, `1.2m`,
`3'6"`, `1,5`. Понимает и арифметику: `1200/4`, `2*300+50`. Строку с пробелами
берут в двойные кавычки: `name="Door 900"`.

Плагину об этом думать не нужно, терминал сам понимает и неточный ввод:

- имя в русской раскладке (`ьщму` → Move);
- опечатку (`Rectnagle`);
- русское слово из `keywords`;
- числа, набранные в русской раскладке (`500б0б0` → `500,0,0`).

## 5. Точки, выделение и клики в модели

Параметр, на который удобнее ответить кликом, терминал спрашивает как Rhino.
Пока вопрос открыт, работает его собственный инструмент с привязками SketchUp.
Ответить можно кликом или с клавиатуры: в терминале или в поле Measurements.
Свой инструмент писать не нужно.

```ruby
T.command(
  id: 'Beam', plugin: 'ArchiTools', description: 'Draw a beam between two points',
  keywords: 'балка', menu: 'Extensions/ArchiTools',
  params: [
    { key: :start,  type: :point,  label: 'Start of beam' },
    { key: :finish, type: :point,  label: 'End of beam', base: :start },
    { key: :height, type: :length, default: 300.mm, prompt: false }
  ],
  preview: ->(args, view) { view.draw(GL_LINES, args[:start], args[:finish]) if args[:finish] }
) do |args|
  ArchiTools::Beam.build(args[:start], args[:finish], args[:height])
end
```

| Тип | Значение в `args` | Как ответить |
|---|---|---|
| `:point` | `Geom::Point3d` | клик; `x,y,z`; `@dx,dy,dz` и `@r<угол` от точки `base`; `r<угол` от начала координат; число — расстояние от `base` в сторону курсора |
| `:vector` | `Geom::Vector3d` | `dx,dy,dz` или `r<угол` (обычно с `optional: true`: `Move 0,0,500`) |
| `:scale` | `[sx, sy, sz]` | `2` или `1,1,2` |
| `:selection` | массив объектов | текущее выделение; если оно пустое, терминал просит выделить и нажать Enter |

| Поле | Значение |
|---|---|
| `base` | ключ точки, от которой считаются `@…` и голое число; от неё же тянется резиновая нить |
| `auto` | значение можно оставить пустым (`Center=Auto`); `auto: ->(args) { ... }` вычисляет его |
| `pick` | `->(point, args) { value }` — ответ кликом и для не-точек: угол, расстояние |
| `kinds` | для `:selection`: `kinds: [Sketchup::Face]` |
| `preselect` | для `:selection`: `false` — не брать то, что уже выделено, а выделить заново. Нужно второму выделению: «чем вычитать» в Subtract |
| `parse` | `->(text, args) { value }` — свой разбор ввода; `nil` — разобрать как обычно |

- `preview: ->(args, view) { ... }` рисует результат, пока пользователь водит
  курсором. В `args` уже стоит значение под курсором. Рисуйте в координатах
  модели.
- `repeat: ->(args) { { start: args[:finish] } }` повторяет команду до Enter или
  Esc. Так Line идёт от точки к точке.
- Точки — в координатах модели. Внутри открытой группы SketchUp сам отдаёт и
  принимает мировые координаты.
- Точки и выделение не запоминаются, остальное запоминается до перезапуска
  SketchUp.
- Пока висит вопрос, Esc в окне модели отменяет команду. Enter и правая кнопка
  мыши работают как Enter в терминале.

Встроенные команды [`draw.rb`](../src/exterminatus/draw.rb),
[`modify.rb`](../src/exterminatus/modify.rb) и
[`native.rb`](../src/exterminatus/native.rb) устроены так же: их можно брать
за образец.

## 6. Что возвращает блок

| Возврат | Что видит пользователь |
|---|---|
| `String` | строка результата |
| `{ ok: true, message: '...' }` | строка результата |
| `{ ok: true, message: '...', created: [объекты] }` | то же; `created` передаётся следующей команде цепочки |
| `{ ok: false, message: '...' }` | ошибка `Id: message`, цепочка останавливается |
| `false` | ошибка `Id failed` |
| `nil`, `true` | ничего |

**Результат как выделение.** Если в цепочке после команды есть ещё одна, то
созданное командой выделяется для неё:

```
Beam 0,0,0 6000,0,0; PathCopy 600
```

PathCopy получит только что построенную балку. Всё новое в текущем контексте
терминал находит сам. `created:` нужен, только если команда меняет не текущий
контекст или создаёт не всё, что следует передать дальше. `SelectLast`
выделяет созданное последней командой и потом.

Шаг отмены (`start_operation` / `commit_operation`) делает сама команда, как и
при вызове из меню. Исключение из блока не роняет терминал: пользователь видит
текст ошибки, а backtrace уходит в Ruby-консоль.

## 7. Приглашения из своего инструмента

Это путь для плагина, у которого уже есть свой инструмент с шагами и который
пока не переведён на параметры. Инструмент пишет текущий шаг в строку
терминала, как Rhino («Pick start point»), и принимает опции:

```ruby
def step_prompt
  BACommunity::Terminal.prompt('Pick start point',
                               options: { 'Mode' => @mode, 'Undo' => nil },
                               tool: true) do |input|
    if input.option == 'Mode'
      @mode = @mode == 'Fit' ? 'Step' : 'Fit'
      step_prompt
    elsif input.option == 'Undo'
      undo_last_point
    elsif input.cancel?
      reset
    elsif !input.enter?
      onUserText(input.text, Sketchup.active_model.active_view)
    end
  end
  Sketchup.status_text = 'Pick start point'
end

def deactivate(view)
  BACommunity::Terminal.prompt(nil)
end
```

- `tool: true` — приглашение уйдёт само, когда пользователь сменит инструмент.
- Без терминала `prompt` возвращает `false`, поэтому `status_text` по-прежнему
  нужен.
- Число, набранное в терминале при активном Ruby-инструменте, уходит
  инструменту в `onUserText`, как ввод в поле Measurements.

## 8. Что пользователь получает бесплатно

Плагину для этого ничего делать не нужно.

- `Help PathCopy` — описание, параметры с типами и значениями по умолчанию,
  `examples`, `keywords`.
- Пресеты:
  - `PresetSave PathCopy Забор` сохраняет текущие опции команды;
  - `PathCopy preset=Забор` или клик по опции `Preset` подставляет их.
- Макросы: `Define Fence "Beam; PathCopy 600"` — и `Fence` становится командой.
  `$1`, `$2` в тексте — значения: `Define Lift "Move 0,0,$1"`, потом `Lift 500`.
- `LibraryExport` / `LibraryImport` — передать пресеты и макросы коллеге одним
  файлом.

## 9. Остальной API

| Метод | Что делает |
|---|---|
| `Terminal.available?` | `true`, если терминал установлен и загружен |
| `Terminal.message(text)` / `Terminal.error(text)` | строка в выводе терминала |
| `Terminal.run('Top; ZoomExtents')` | выполнить строку команд; в историю не попадает |
| `Terminal.register(...)` | только команда терминала, без меню (API версии 1; новым плагинам — `command`) |
| `Terminal.unregister('Id')` | снять команду (для разработки) |
| `Terminal.version` | версия терминала |

Второй аргумент блока `ctx` даёт `ctx.message` / `ctx.error` для
промежуточных сообщений длинной команды. Без терминала сообщение идёт в
строку состояния, ошибка — в окно.

## 10. Проверка

1. Установите терминал и плагин, перезапустите SketchUp.
2. Наберите в терминале `PluginCheck <имя плагина>`. Команда показывает:
   - отказы регистрации (занятое имя);
   - длины по умолчанию без `.mm`;
   - точки без `label` и `preview`;
   - отсутствующие иконки;
   - устаревшие копии моста.
3. `Help <команда>` для каждой команды: понятно ли, что она спрашивает?
4. Каждую команду проверьте трижды:
   - набором в терминале;
   - кликом по пункту меню;
   - кликом по кнопке.
5. Отключите Exterminatus в Extension Manager, перезапустите SketchUp и
   кликните те же пункты меню. Плагин должен работать без терминала.

## Переход с версии 1

Плагин с мостом версии 1 (`Terminal.register` рядом со своим меню) работает
и дальше. Чтобы перейти:

1. Замените `terminal_bridge.rb` новой копией.
2. Для каждой команды объедините `register` и свой `UI::Command`: ключи
   `menu`, `menu_text`, `toolbar`, `icon` переходят в `T.command`, блок
   остаётся тем же.
3. Удалите из `main.rb` ставшие лишними `UI::Command.new`, `add_item` и
   `UI::Toolbar`. Старую логику пункта меню, если она отличалась от команды,
   перенесите в `fallback:`.
4. Добавьте `keywords:` и `examples:`, запустите `PluginCheck`.
