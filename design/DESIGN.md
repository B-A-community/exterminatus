# Exterminatus: визуальная концепция

Терминал — компактное поле ввода на светло-серой панели. Основной ориентир — Measurements / VCB: рабочая область важнее управляющего элемента. Segoe UI 12 CSS px, межстрочный интервал 18 px, тонкие рамки, радиус 2 px. Моноширинный шрифт используется только для идентификаторов команд и эха.

Measurements действительно меняет назначение в зависимости от активного инструмента — этот принцип использован для смены команды на запрос параметра. Источник: [SketchUp Help — Using the Measurements Box](https://help.sketchup.com/en/using-measurements-box).

## Палитра

| Назначение | Цвет | Обоснование |
|---|---|---|
| Панель | #F0F0F0 | Приближение к классической светлой поверхности Windows |
| Поле и подсказки | #FFFFFF | Привычная поверхность ввода |
| Основной текст | #262626 | Читаемый, без абсолютного чёрного |
| Вторичный текст | #666666 | Описания и значения остаются различимыми |
| Рамка | #B8B8B8 | Тонкая граница поля |
| Разделитель | #D3D3D3 | Мягкое разделение областей |
| Hover | #E5E5E5 | Нейтральная обратная связь |
| Фокус поля | #606060 | Чёткая рамка без цветного свечения |
| Активная подсказка | #0067C0 / #FFFFFF | Сдержанное выделение в духе Windows |
| Ошибка | #873B35 | Тёмно-красный текст без плашки |

Цвета — дизайнерское приближение к заданному светлому интерфейсу SketchUp 2024 для Windows, а не извлечённые ресурсы SketchUp и не измерение его скриншота. Официальная справка подтверждает назначение VCB, но не значения цветов. Точная сверка палитры требует эталонного скриншота целевой установки.

Все цвета и основные размеры находятся в `:root`. Внешних ресурсов нет. Системный режим повышенной контрастности поддержан отдельно; это не тёмная тема.

## Размеры и компоновка

Размеры указаны для клиентской области в CSS px, без системной рамки и заголовка HtmlDialog.

- Bar: обычно 720 × 110. Рекомендуемый минимум 320 × 110.
- Bar с раскрытыми подсказками: для обзора удобна высота 220. При 110 список остаётся внутри окна и прокручивается.
- Popup: обычно ширина 460, минимум 320. Высота от 38 до 320 по содержимому.
- Поле: 26 px. Подсказка: минимум 42 px, две строки.
- В bar лог занимает свободную область сверху, подсказки располагаются перед нижней строкой ввода.
- В popup ввод сверху, подсказки снизу. История скрыта. Необязательный класс `has-result` показывает только последнюю строку лога, максимум в две визуальные строки.

CSS не меняет размер нативного HtmlDialog. Измерение содержимого, изменение размеров окна и ограничение его положения границами экрана реализует разработчик в Ruby/JS.

## Поведение

Hover подсказки серый; активный пункт синий. Совпадения подчёркнуты и выделены полужирным, без цветного фона. На активной строке весь текст белый для читаемости.

Фокус поля обозначается тёмно-серой рамкой без изменения размеров. Опции параметров подчёркнуты, при наведении получают серый фон, при клавиатурном фокусе — пунктирный контур.

Приглашение располагается перед полем. Если места недостаточно, поле переносится на следующую строку. Опции переносятся целиком; длинный текст допускает разрыв. Для аномально длинного приглашения предусмотрена прокрутка.

Занятость показывает серая линия толщиной 2 px. Место под неё зарезервировано постоянно. При reduced motion линия неподвижна. Отключение ввода во время выполнения — отдельное решение контроллера; класс `is-busy` сам по себе его не отключает.

Ошибки начинаются с `Error:`, поэтому распознаются не только по цвету.

## Контракт для разработчика

`index.html` не содержит команд, результатов или демонстрационных опций. Динамические строки добавляются внутрь предусмотренных контейнеров.

- Лог: `div.line` с одним из `line--echo`, `line--info`, `line--result`, `line--error`.
- Параметр: текст в `.prompt__text`, значение вместе с угловыми скобками в `.prompt__default`.
- Опция: `span.opt[data-opt]`, внутри `.opt__name` и необязательный `.opt__value`. Значение включает `=`, например `=10`. Скобки и двоеточие добавляются текстом.
- Опциям нужны `role="button"`, `tabindex="0"` и обработка Enter/Space.
- Подсказка: `div.sg`, внутри `.sg__id`, `.sg__plugin`, `.sg__desc`. Совпадения оборачиваются в `mark`.
- Активной подсказке назначаются `.sg--active`, уникальный `id` и `aria-selected="true"`; остальным — `aria-selected="false"`. Каждая имеет `role="option"`.
- Поле сохраняет фокус при перемещении по списку; контроллер обновляет `aria-activedescendant`, `aria-expanded` и прокручивает активный пункт в видимую область.
- При запросе параметра обновляется доступное имя поля, например на `Step`.
- `is-busy` на body управляет индикатором; `aria-busy` на `.terminal` обновляется одновременно.
- Подсказка `Enter — repeat last` изначально скрыта: показывать только при наличии последней команды.
- Вставлять пользовательский текст безопасно, через текстовые узлы; `mark` создавать отдельно.

В popup Enter выполняет выбранную команду и скрывает окно; Esc скрывает окно. Для многошаговой команды запрос параметра должен сохранять или повторно открывать popup до завершения ввода. Bar остаётся открытым. Обработка клавиш, возврат фокуса SketchUp и выполнение команд относятся к terminal.js / Ruby.

## Сознательно исключено

Нет логотипа, собственного заголовка внутри страницы, ярких кнопок, теней, крупных скруглений, декоративных иконок, тёмной темы и анимаций появления. Синий используется для выбранной подсказки и стандартного выделения текста.

Preview собирает независимые статичные iframe: оба режима, пустое поле, автодополнение, параметр, все четыре вида строк лога, результат, занятость и узкое окно. JS демо только создаёт примеры, команды не выполняет. Названия команд условные.

Файлы не записывались. Визуальная проверка в SketchUp / CEF 112 не выполнялась; финальная сверка нужна в целевом HtmlDialog, включая масштаб Windows 125% и 150%.
