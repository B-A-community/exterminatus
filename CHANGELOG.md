# Журнал изменений

## 0.4.2 — 2026-10-25

- Исправлено: после нескольких нажатий Backspace строка терминала
  становилась пустой. Причина: в окнах SketchUp Backspace вне поля ввода
  работает как «Назад» браузера. Теперь клавиши, нажатые мимо поля,
  попадают в поле, а при фокусе на окне курсор сразу ставится в строку.
- Исправлено: если строку закрыть и сразу открыть, она могла не появиться.

## 0.4.1 — 2026-10-25

- В окне Plugin Updates ссылка на страницу плагина называется «Plugin page»,
  ссылка на каталог сайта — «All plugins».
- Из окна убрана кнопка «Roll back to …». Откат остался командой терминала
  `PluginRollback`.

## 0.4.0 — 2026-10-25

- Новые плагины попадают в список сами. Каталог перебирает все публичные
  репозитории B-A-community и берёт те, у которых есть релиз 1.0+ с
  `.rbz`. Имя расширения и папка берутся из пакета: строкой или константой
  в загрузчике или в файлах папки плагина. `plugins.json` теперь только
  уточняет порядок и подписи.
- Как убрать плагин из списка:
  - тема репозитория `exterminatus-ignore` или `hidden` в `plugins.json` —
    не показывать;
  - архив репозитория или `retired` с причиной — новые не ставятся, у кого
    стоит, видят «Retired» и причину.
- Exterminatus доверяет каталогу только записи о репозиториях B-A-community,
  ассеты из их же релизов по HTTPS с sha256 и безопасные имена папок.
- Последний каталог хранится в `catalog_cache.json` и показывается, если
  GitHub не отвечает.
- `test/catalog_discovery.rb` проверяет определение плагинов на настоящих
  релизах.
- В окне Plugin Updates — ссылки на страницу плагина на pachka.space и на
  отзывы, вверху — на весь каталог. Ссылки сборщик берёт из API сайта, по
  имени репозитория; `page` в `plugins.json` задаёт ссылку явно.

## 0.3.2 — 2026-10-25

- Исправлено: после обновления плагина из окна Plugin Updates Exterminatus
  при следующем запуске SketchUp падал с SyntaxError («Some Extensions
  Failed to Load»). Причина в том, что `Sketchup.write_default` портит
  строки с кавычками. Из-за этого же не сохранялась история команд.
- История команд и отметки «ждёт перезапуска» теперь хранятся в файлах в
  `%APPDATA%\BACommunity\Exterminatus`. Старые испорченные значения из
  настроек SketchUp удаляются при запуске.
- Сбой проверки обновлений больше не мешает терминалу загрузиться.

## 0.3.1 — 2026-10-25

- Булавка в строке терминала: закреплённая строка не закрывается после
  команды и по Esc, не прыгает к курсору. Она стоит там, куда её
  перетащили, и сворачивается и возвращается вместе с окном SketchUp.
- Пробел — как Enter, как в Rhino: подтверждает команду и ответ. В кавычках
  и в текстовых ответах это обычный пробел; Shift+пробел — обычный пробел
  для аргументов в строке.
- Line больше не пересоздаёт инструмент на каждом отрезке: это доводило
  SketchUp до зависания. Наблюдатель на каждую команду убран.

## 0.3.0 — 2026-10-25

- Exterminatus ставит и обновляет наши плагины из релизов GitHub
  B-A-community. Окно Extensions → Exterminatus → Plugin Updates…:
  - Update, Install (RU/EN), Roll back и Update all;
  - перезапуск SketchUp кнопкой.

  Команды Plugins, PluginUpdate, PluginInstall, PluginRollback, PluginUpdates,
  RestartSketchUp.
- Файл проверяется по размеру и sha256 от GitHub. Из релизного zip
  достаётся `.rbz`, ставится штатно, как в Extension Manager. Язык и версия
  установленного плагина определяются без правок в самих плагинах.
- Проверка обновлений раз в сутки при запуске, с сообщением в терминале.
- Каталог `catalog.json` собирает GitHub Actions раз в час. Пока каталога
  нет, релизы читаются напрямую через GitHub API.
- В первом списке — плагины, которые уже в работе: RAL/NCS, Area counter,
  Monsieur Bézier, PathCopy Advanced. Плюс сам Exterminatus, когда его
  репозиторий появится на GitHub.
- docs/RELEASES.md — как выпускать релизы и добавлять плагины в список.

## 0.2.0 — 2026-10-25

Терминал поддерживает только наши плагины и родные команды SketchUp.

**Для плагинов**

- Мост версии 2: `Terminal.command` описывает команду один раз. Из описания
  получаются пункт меню, кнопка на панели, команда терминала, справка, поиск
  по русским словам и пресеты.
- Клик по пункту меню при установленном терминале работает как набранная
  команда. Без терминала пункт меню работает сам: выделение берётся из
  модели, параметры спрашиваются окном, либо вызывается `fallback:`. Каждая
  копия моста в плагине своя, используется самая новая.
- Новые ключи параметров:
  - `suggest:` — варианты для строки (теги, материалы);
  - `preselect: false` — второе выделение выделяется заново.

  Новые ключи команды: `keywords:`, `examples:`, `destructive:`.
- `created:` в результате команды и автоматический поиск созданного:
  созданное передаётся следующей команде цепочки.
- `PluginCheck` проверяет подключение:
  - занятые имена;
  - длины без `.mm`;
  - точки без подписи и предпросмотра;
  - иконки;
  - старые копии моста.
- Документы: `docs/INTEGRATE.md` (пошагово, с заданием для Claude или Codex),
  обновлённый `docs/PLUGIN_GUIDE.md`, пример `examples/hello_plugin`.

**Для пользователя**

- Неточный ввод:
  - русская раскладка в именах, числах и параметрах (`ьщму` → Move,
    `500б0б0`);
  - русские слова (`круг`, `выдавить`);
  - опечатки (`Rectnagle`).

  Команды, которые удаляют, по опечатке не запускаются.
- `Help <команда>` — параметры, опции, примеры и слова.
- Цепочки передают созданное дальше: `Rectangle 0,0 1000,500; PushPull 300`.
  `SelectLast` выделяет созданное последней командой.
- Макросы: `Define`, `Undefine`, `Macros`, значения `$1`…`$9`.
- Пресеты: `PresetSave`, `preset=`, опция `Preset`, `Presets`, `PresetDelete`.
- `LibraryExport` / `LibraryImport` переносят макросы и пресеты одним файлом.
- Новые команды SketchUp:
  - SetTag, SetMaterial, Rename, Info, Isolate, Unisolate;
  - Guide, GuidePoint, DimLinear, Label, SectionAt;
  - Sweep, Soften, Unsoften, Mirror;
  - Union, Subtract, SolidIntersect, OuterShell.
- После выделения по вопросу Enter сразу запускает команду: лишнего
  «Press Enter to run» больше нет.

## 0.1.0 — 2026-10-24

Первая тестовая сборка, релиза нет.

- Терминал в двух режимах: плавающая полоса с выводом (Command Bar) и строка
  у курсора по горячей клавише (Terminal). Когда полоса открыта, горячая
  клавиша ставит фокус в неё.
- Автодополнение по началу имени, по заглавным буквам (`ze` → ZoomExtents),
  по подстроке и по синонимам. Часто вызываемые команды поднимаются выше.
- История строк (стрелки, 200 строк между сеансами). Enter или пробел в
  пустой строке повторяет последнюю команду. Цепочки через `;`.
- Параметры в стиле Rhino: приглашение `Step <500 mm> ( Mode=Fit Count=10 ):`,
  кликабельные опции, аргументы в строке (`PathCopy 300 mode=fit`),
  запоминание последних значений. Типы: длина, число, целое, угол, строка,
  вариант, да/нет.
- Приглашения из Ruby-инструментов (`Terminal.prompt`). Числа, набранные при
  активном Ruby-инструменте, уходят ему в `onUserText`.
- 94 стандартные команды SketchUp: инструменты рисования, правки и камеры,
  стандартные виды, стили граней, переключатели отображения, правка
  выделения, группы и компоненты, сцены, файл. Синонимы — стандартные клавиши
  SketchUp (L, R, P, M…).
- Команды правки в духе Rhino: Move, Copy, Rotate, Scale, PolarArray, Offset,
  PushPull. Строка говорит, что нужно (`Point to move from`), а ответить
  можно кликом в модели с привязками SketchUp или с клавиатуры — в терминале
  или в поле Measurements. Резиновая нить и пунктирный предпросмотр. Без
  выделения команда просит выделить (клик, рамка, Enter или правая кнопка).
  Всё сразу пишется и в строке: `Move 0,0,500`, `Copy 1000,0,0 count=5`,
  `Rotate 90 axis=x copy=yes`, `Scale 1,1,2`, `Offset 50`, `PushPull 20`.
- Рисование в духе Rhino: Line (идёт дальше от последней точки до Enter,
  замкнутый контур становится гранью), Rectangle (два угла или размер
  `3000,2000`), Circle (центр и радиус, `Segments`). Rectangle и Circle
  ложатся на грань под первым кликом (`Plane=Auto`) или на XY/XZ/YZ.
- Arc (концы и прогиб), ArcCenter и Pie (центр, начало, угол или конечная
  точка), Polygon (центр и вершина или радиус, `Sides`, `Mode`) — так же,
  кликом или вводом.
- Новые типы параметров: точка (`x,y,z`, `@dx,dy,dz`, `r<угол`, `@r<угол`,
  число — расстояние в сторону курсора), вектор, множитель, выделение. Поля
  `label`, `base`, `auto`, `pick`, `ask_if`, `parse`, у команды — `preview`
  и `repeat`.
- Опцию можно задать набором `Count=3` прямо в ответ на вопрос.
- Имя другой команды, набранное, пока команда ждёт ответа, отменяет её и
  запускает новую; подсказки команд при этом видны. Раньше пробел, который
  повторял последнюю команду, мог оставить терминал «зависшим» на её вопросе.
- Арифметика в значениях: `1200/4`, `2*300+50`, `1.2m-300`.
- Копирование в буфер переименовано в `CopyToClipboard`: имя `Copy` теперь у
  копирования со смещением, как в Rhino. У параметров есть `optional: true`.
- Assign Shortcut…: горячая клавиша терминала без похода в Preferences
  (Windows). Правка SharedPreferences.json скрытым PowerShell после закрытия
  SketchUp, копия настроек рядом, по желанию — перезапуск.
- Мост `terminal_bridge.rb` и гайд для плагинов `docs/PLUGIN_GUIDE.md`.
- Дизайн — Codex (gpt-6-astra): окно в стиле родных панелей SketchUp 2024.
